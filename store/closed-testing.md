# 비공개 테스트 (프로덕션 액세스 요건)

개인 개발자 계정은 **테스터 12명 이상이 14일 연속 옵트인** 상태를 유지해야 프로덕션 액세스를 신청할 수 있다.
계정당 1회만 통과하면 이후 앱은 면제.

| 항목 | 값 |
|---|---|
| 트랙 | 비공개 테스트 - Alpha (앱 ID 4972327766453903926) |
| 버전 | 1.0.0 (versionCode 3, 실제 AdMob ID) — 2026-09-16 검토 제출 |
| 국가 | 177개 전체 |
| 테스터 목록 | "Internal testers" (Play Console → 비공개 테스트 → 테스터 탭에서 이메일 추가) |
| 옵트인 링크 (웹) | https://play.google.com/apps/testing/com.jun5731.puzzle_2048 |
| 스토어 링크 (옵트인 후 설치) | https://play.google.com/store/apps/details?id=com.jun5731.puzzle_2048 |

## 테스터 추가 절차
1. Play Console → 테스트 및 출시 → 비공개 테스트 → "Alpha" 트랙 관리 → 테스터 탭 → "Internal testers" 화살표 → 이메일 추가 → 저장
2. 테스터에게 아래 안내문 전송
3. 테스터가 옵트인 링크에서 "테스트 참여" → 스토어 링크에서 설치 (검토 통과 전에는 링크가 "아직 사용할 수 없음"으로 뜸)
4. 14일 후 대시보드에서 "프로덕션 액세스 신청" → 설문 작성

Google Play 정책상 테스터 12명이 14일 동안 참여해야 정식 출시가 가능합니다.

   https://play.google.com/apps/testing/com.jun5731.puzzle_2048
