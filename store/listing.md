
## 간단한 설명 (80자)

```
밀고 합쳐서 2048을 만드는 클래식 숫자 퍼즐. 되돌리기와 이어하기로 부담 없이 즐기세요.
```

## 자세한 설명 (4,000자)

```
🎯 밀고, 합치고, 2048에 도전하세요

「2048 퍼즐」은 화면을 상·하·좌·우로 밀어 같은 숫자의 타일을 합치는 클래식 숫자 퍼즐 게임입니다.
회원가입도, 로그인도 필요 없습니다. 열자마자 바로 플레이할 수 있어요.

✨ 주요 기능

• 간단한 조작
  한 손가락으로 밀기만 하면 됩니다. 규칙은 단 하나, 같은 숫자끼리 합치기!

• 되돌리기
  실수한 한 수를 되돌릴 수 있습니다. 게임마다 3회 무료, 부족하면 짧은 광고를 보고 충전하세요.

• 이어하기
  앱을 닫아도 진행 중인 게임이 그대로 저장됩니다. 언제든 이어서 플레이하세요.

• 최고 기록
  나의 최고 점수를 기록하고 스스로에게 도전하세요.

• 2048 그 너머로
  2048 타일을 만든 뒤에도 계속 플레이하며 4096, 8192에 도전할 수 있습니다.

• 부드러운 애니메이션
  타일이 미끄러지고 합쳐지는 손맛을 살린 애니메이션과 햅틱 피드백.

🎨 깔끔한 디자인

눈이 편한 클래식 색상에 다크 모드까지 지원합니다. 세로 화면에 최적화되어 한 손으로 편하게 즐길 수 있어요.

🔒 개인정보 걱정 없이

게임 기록은 휴대폰 안에만 저장되며 어떤 서버로도 전송되지 않습니다.
가볍고 빠르며, 불필요한 권한을 요구하지 않습니다.

---
※ 앱은 광고를 포함하고 있습니다.
```
